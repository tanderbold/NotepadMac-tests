# L10N — Localization of the interface

The interface in another language: choosing it (launch option `-NppMac.localizationFile
<file>.xml`, Preferences > General > Localization), menus translated by command id from
Notepad++'s own `nativeLang/*.xml` (PowerEditor/installer/nativeLang), menus and submenus by
upstream's menuId / subMenuId, dialogs and messages by their English text, the port's own texts
from `macos/resources/nativeLang-extra/<file>.xml`, the status bar with upstream's statusbar
strings, right-to-left languages, and dialogs checked for cut-off or untranslated text. The
tests read the translation files from `../npp/PowerEditor/installer/nativeLang` and
`../npp/macos/resources/nativeLang-extra` to know what to expect. Out of scope: the content of
each dialog (their own areas); what the commands do.

## Choosing the language

### L10N-001: Launching in Russian translates the menu bar
- Covers: -
- Channel: launch, menu, modal
- Steps: `app.start(args=["-NppMac.localizationFile", "russian.xml"])`; dump `e2e_menu tree=main depth=0`; read the modal log.
- Expect: the top menus read Файл, Правка, Поиск, Вид, Кодировки, Синтаксисы, Опции, Инструменты, Макросы, Запуск, Плагины, Вкладки (upstream's menuId names) and the application menu stays "NotepadMac"; the modal log is empty (the option's value is not taken for a file to open).

### L10N-002: Menu commands are translated by their command id
- Covers: IDM_VIEW_*, IDM_EDIT_RTL, IDM_EDIT_LTR, IDM_FILE_*, IDM_EDIT_*, IDM_SEARCH_*
- Channel: launch, menu
- Steps: For each of russian.xml, german.xml, french.xml, japanese.xml, chineseSimplified.xml, finnish.xml: launch in it; for every `Menu/Main/Commands/Item` of the file whose id is in commands.tsv, read the item's title with `e2e_menu` by id.
- Expect: every item found shows the file's `name` with the `&` access keys removed (and `...` matched to `…`); in particular View › View Current File in › Edge (44102) reads the file's text for 44102, not the translation of some other "Edge"; items the file does not translate keep their English title.

### L10N-003: Submenus are translated by their subMenuId
- Covers: -
- Channel: launch, menu
- Steps: Launch in german.xml; dump the View and Edit menus to depth 1.
- Expect: the submenus that upstream names by subMenuId (view-showSymbol, view-zoom, view-moveCloneDocument, view-currentFileIn, view-tab, view-collapseLevel, view-uncollapseLevel, view-project, edit-copyToClipboard, edit-lineOperations, edit-convertCaseTo, edit-eolConversion) read the German `name` of that subMenuId from german.xml.

### L10N-004: Switching the language in Preferences applies at once and back
- Covers: IDM_SETTING_PREFERENCE
- Channel: ui, menu
- Steps: Dump the main menu tree (depth 2), the status bar text, the tab menu and Document List's dock title in English; open Preferences, on the General page select "Русский" in the Localization popup, click Apply; dump them again; select "English", Apply; dump again.
- Expect: after the Russian Apply the menus, the status bar ("длина:"), the tab menu ("Закрыть") and the dock title ("Список Файлов") are Russian without a restart, and the Preferences window itself is Russian; after switching back every dump is identical to the first English one.

### L10N-005: The chosen language survives a restart
- Covers: IDM_SETTING_PREFERENCE
- Channel: ui, launch, prefs
- Steps: Choose "Deutsch" in Preferences and Apply; read pref `localizationFile`; `app.restart()`; read the File menu's title and IDM_FILE_NEW's title.
- Expect: the pref is "german.xml"; after the restart the menus are German ("Datei", and IDM_FILE_NEW's German name).

### L10N-006: The language list names each language in itself
- Covers: IDM_SETTING_PREFERENCE
- Channel: ui
- Steps: Launch in russian.xml; open Preferences on General; read the Localization popup's items and selection.
- Expect: one item per file of the nativeLang folder, each the file's `Native-Langue name` attribute (English, Deutsch, Français, Русский ...); "Русский" is selected.

### L10N-007: An unknown language file leaves the interface in English
- Covers: -
- Channel: launch, menu, ui
- Steps: Launch with `-NppMac.localizationFile nosuch.xml`; dump the File menu; open a document; then launch with `english.xml`.
- Expect: English menus and status bar in both cases; the application runs normally (a document can be opened and edited).

## What is translated

### L10N-008: The port's own texts are translated from nativeLang-extra
- Covers: -
- Channel: launch, menu, ui
- Steps: For russian.xml and german.xml: launch in the language; for every `Item` of `nativeLang-extra/<file>` whose English text is the title of an item in the English main menu (dumped beforehand), read that item; also read the "View|Toggle Insert/Overtype" and "View|Show All Hidden Lines" items and the status path field's tooltip on a saved file.
- Expect: every such menu item shows the extra file's `text` (e.g. Russian "Переключить вставку/замену", "Показать все скрытые строки"); the path tooltip is "Щёлкните, чтобы скопировать полный путь" in Russian.

### L10N-009: "Copied" feedback in the interface language
- Covers: -
- Channel: launch, ui, clipboard
- Steps: Launch in russian.xml; open `<tmp>/a.txt`; click the status path field (hook: click on a control without action, as in UI-039); read the field.
- Expect: "✓ Скопировано: <full path>"; the clipboard holds the path.

### L10N-010: The status bar speaks the language
- Covers: -
- Channel: launch, ui
- Steps: For russian.xml, german.xml and finnish.xml: launch in it; new document "ab\ncd\nef"; read the status field; select from line 1 column 1 to line 2 column 3 ("ab\ncd"); read it again.
- Expect: Russian contains "длина: 8", "Стр: 3" and then "Выд: 5 | 2" and the language "Обычный Текст"; German contains "Länge: 8"; Finnish "pituus: 8    rivejä: 3"; none contains "length:"; the EOL name stays "Unix (LF)" and the encoding "UTF-8" (upstream does not translate them).

### L10N-011: The tab and editor context menus are translated
- Covers: IDM_FILE_CLOSE, IDM_FILE_CLOSEALL_BUT_CURRENT
- Channel: launch, menu
- Steps: Launch in russian.xml; dump `e2e_menu context=tab` and `context=editor`.
- Expect: the tab menu uses the file's TabBar wording ("Закрыть", "Закрыть все Кроме Текущей", "Закрепить Вкладку", its submenus translated too); every editor context-menu item has the same title as the main-menu item for its command (e.g. Cut = IDM_EDIT_CUT's Russian name); no item of either menu is left in English when the file translates it.

### L10N-012: Panel titles are translated, docked and floating
- Covers: IDM_VIEW_FUNC_LIST, IDM_VIEW_DOC_MAP, IDM_VIEW_DOCLIST
- Channel: launch, ui
- Steps: Launch in russian.xml; show Function List, Document Map, Document List; read `titleOf:` for each (NppDockingManager); float Function List; read its window title.
- Expect: "Список Функций", "Карта Документа", "Список Файлов" (the file's panel titles); the floating window is titled "Список Функций".

### L10N-013: Messages are shown in the interface language
- Covers: IDM_FILE_RELOAD, IDM_VIEW_SUMMARY
- Channel: launch, modal
- Steps: Launch in russian.xml; open a saved file, type "x", queue alert answer 2, run IDM_FILE_RELOAD; queue answer 1 and run IDM_VIEW_SUMMARY; read the modal log (hook: the log records alerts as shown, after translation).
- Expect: the reload question's text and buttons are the Russian ones from russian.xml (not "Are you sure you want to reload"); the Summary alert is titled with the file's `summary` text ("Информация о Файле") and its lines use the file's summary labels; no English sentence remains where the file has a translation.

### L10N-014: Shortcuts keep working in another language
- Covers: IDM_VIEW_ZOOMIN, IDM_SEARCH_FIND, IDM_EDIT_SELECTALL
- Channel: launch, keys, menu
- Steps: Launch in german.xml; read the key of IDM_VIEW_ZOOMIN, IDM_SEARCH_FIND, IDM_EDIT_SELECTALL; press `cmd++` (Zoom In's key; `cmd+=` is Edit > Calculate), `cmd+a`, `cmd+f`.
- Expect: the keys are the same as in English (cmd++, cmd+a, cmd+f); zoom goes to 1, all text is selected, the Find window opens with a German title.

## Dialogs in other languages

### L10N-015: Nothing is cut off in dialogs, in long-word and CJK languages
- Covers: IDM_SEARCH_FIND, IDM_SEARCH_REPLACE, IDM_SEARCH_FINDINFILES, IDM_SEARCH_MARK, IDM_SETTING_PREFERENCE, IDM_SEARCH_GOTOLINE, IDM_EDIT_COLUMNMODE, IDM_LANGSTYLE_CONFIG_DLG, IDM_SETTING_SHORTCUT_MAPPER
- Channel: launch, ui, snapshot
- Steps: For each of german.xml, finnish.xml, hungarian.xml, russian.xml, french.xml, japanese.xml, chineseSimplified.xml: launch in it; open Find (every tab), Preferences (pages General, Toolbar, Tab Bar, Editing, New Document, Searching, MISC.), Go To, Column Editor, Style Configurator, Shortcut Mapper; read every visible label and button with its frame and needed size (hook: `cell_size`/`wraps` in `e2e_ui`); snapshot each; close.
- Expect: every non-wrapping label and button fits its frame (needed width and height ≤ frame + 1.5 px); no two visible controls on one page overlap; nothing lies outside its window; snapshots kept as artefacts.

### L10N-016: No English left where the translation has the text
- Covers: IDM_SEARCH_FIND, IDM_SETTING_PREFERENCE, IDM_SEARCH_GOTOLINE, IDM_EDIT_COLUMNMODE
- Channel: launch, ui
- Steps: In English, dump the controls of Find (Find and Replace tabs), Preferences (General, Editing), Go To and Column Editor (path → title/value); then for russian.xml and german.xml dump the same windows; for each control at the same path, look its English text up in the nativeLang file (Dialog section, same key as in english.xml) and in the nativeLang-extra file.
- Expect: every control whose English text has a translation in either file shows that translation (ignoring access keys, a trailing ":" and "…"); the window titles are translated too.

### L10N-017: Right-to-left languages
- Covers: IDM_SEARCH_FIND, IDM_SETTING_PREFERENCE
- Channel: launch, menu, ui, snapshot
- Steps: For each of arabic.xml, hebrew.xml, farsi.xml, urdu.xml: launch in it; read the titles of the top menus and of 20 View commands; type "abc שלום مرحبا" into a new document; read the status field; open Find and Preferences (General) and check them as in L10N-015; snapshot the main window and the dialogs.
- Expect: the menus show the file's texts (checked as in L10N-002); the status bar shows the file's statusbar strings; the document keeps the typed text exactly (`get_document`) and the editor draws it (the text region of the snapshot is not blank); no control is cut off in the dialogs.

### L10N-018: Every translation loads and yields a usable interface
- Covers: -
- Channel: launch, menu, ui
- Steps: For each `*.xml` of the nativeLang folder (about 90): launch with `-NppMac.localizationFile <file>`; dump the main menu (depth 0) and the File menu; read the status field; stop.
- Expect: the application starts and answers every time; no top menu or File command has an empty title; the application menu is "NotepadMac" and its first item still contains "NotepadMac"; the status field is non-empty.
